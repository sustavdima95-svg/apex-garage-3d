# Apex Garage 3D

Build and test-drive a custom car in your browser. Seven body styles, five tuning categories, damage, nitro and a 2 × 2 km driving area.

## Play

The game will open at https://sustavdima95-svg.github.io/apex-garage-3d/ once GitHub Pages is enabled.

## Controls

- W / ↑ accelerates
- S / ↓ brakes and reverses
- A / D or ← / → steers
- Space uses the handbrake
- Shift with acceleration uses nitro

## Windows app

The Windows download is being prepared for web hosting. When available, extract the entire ZIP and open ApexGarage3D.exe.
