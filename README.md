# Apex Garage 3D

Build and test-drive a custom car in your browser. Seven body styles, five tuning categories, damage, nitro and a 8 × 8 km driving area.

## Play

The game will open at https://sustavdima95-svg.github.io/apex-garage-3d/ once GitHub Pages is enabled.

## Controls

- W / ↑ accelerates
- S / ↓ brakes and reverses
- A / D or ← / → steers
- R returns the car to its wheels after a crash
- Space uses the handbrake
- Shift with acceleration uses nitro

## Windows app

Download the Windows, Linux or macOS ZIP from the game's download menu. Extract it before launching the app. On Linux, run the enclosed AppImage. On macOS, open the enclosed .app bundle.
